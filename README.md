# SkillBridge — Frontend (SIH Demo)

A frontend-only React + Vite + Tailwind implementation of the Portal for
Academia–Industry Collaboration PRD. It's built around mock data (no backend)
so you can run and demo it immediately, then wire it up to a real API later.

## Run it

npm install
npm run dev

Then open the printed local URL (usually http://localhost:5173).
